# src

Codigo modular del mapa.

- `js/`: modulos JavaScript auxiliares y funcionalidades complementarias.
- `css/`: estilos modulares del portal y de Nichos V2.

Los archivos `app.js` y `styles.css` permanecen temporalmente en la raiz porque son los puntos de entrada historicos del mapa y moverlos implicaria cambiar rutas de edicion y despliegue adicionales.
